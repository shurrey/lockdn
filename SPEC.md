Student Course Tools - Product Specification                                                                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                                                                                              │
     │ Executive Summary                                                                                                                                                                                                                                                                                            │
     │                                                                                                                                                                                                                                                                                                              │
     │ An open-source, local-first web application that helps undergraduate students organize their academic lives by extracting assignments from syllabi, intelligently planning study time, providing AI-powered tutoring with academic integrity safeguards, and generating study materials from uploaded notes. │
     │                                                                                                                                                                                                                                                                                                              │
     │ ---                                                                                                                                                                                                                                                                                                          │
     │ Core Design Principles                                                                                                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                                                                                              │
     │ 1. Local-first architecture: All data stored on student's device with optional P2P sync                                                                                                                                                                                                                      │
     │ 2. BYOK (Bring Your Own Key): Students provide their own AI API keys, ensuring sustainability and privacy                                                                                                                                                                                                    │
     │ 3. Academic integrity by design: Context-aware tutoring that guides rather than gives answers                                                                                                                                                                                                                │
     │ 4. Smart dashboard as hub: AI-prioritized "what needs attention" drives the experience                                                                                                                                                                                                                       │
     │ 5. Wise mentor persona: Warm but authoritative tone, like a helpful TA                                                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                                                                                              │
     │ ---                                                                                                                                                                                                                                                                                                          │
     │ Target Users                                                                                                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                                                                                              │
     │ - Primary: Undergraduate students (4-year college/university)                                                                                                                                                                                                                                                │
     │ - Context: Managing multiple courses, varied disciplines, independent study                                                                                                                                                                                                                                  │
     │ - Tech profile: Desktop/laptop primary, comfortable with web apps                                                                                                                                                                                                                                            │
     │                                                                                                                                                                                                                                                                                                              │
     │ ---                                                                                                                                                                                                                                                                                                          │
     │ Feature Specifications                                                                                                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                                                                                              │
     │ 1. Syllabus Parsing & Calendar                                                                                                                                                                                                                                                                               │
     │                                                                                                                                                                                                                                                                                                              │
     │ Input Handling:                                                                                                                                                                                                                                                                                              │
     │ - Accept PDFs, Word documents, images, and plain text                                                                                                                                                                                                                                                        │
     │ - Aggressive extraction strategy - pull everything possible                                                                                                                                                                                                                                                  │
     │ - Use vision models for complex layouts, tables, and non-standard formats                                                                                                                                                                                                                                    │
     │                                                                                                                                                                                                                                                                                                              │
     │ Extraction Safeguards:                                                                                                                                                                                                                                                                                       │
     │ - Confidence indicators on each extracted item                                                                                                                                                                                                                                                               │
     │ - Mandatory review workflow - student must approve before items are added                                                                                                                                                                                                                                    │
     │ - Diff view when syllabus is re-uploaded (show what changed)                                                                                                                                                                                                                                                 │
     │ - Clear disclaimer that accuracy isn't guaranteed                                                                                                                                                                                                                                                            │
     │                                                                                                                                                                                                                                                                                                              │
     │ Calendar Features:                                                                                                                                                                                                                                                                                           │
     │ - Continuous timeline (no explicit semester boundaries)                                                                                                                                                                                                                                                      │
     │ - Mixed time granularity: deadlines as dates, study sessions as time-blocks                                                                                                                                                                                                                                  │
     │ - Course-color-coded visualization                                                                                                                                                                                                                                                                           │
     │ - Filter by course, type (exam, paper, homework), or date range                                                                                                                                                                                                                                              │
     │                                                                                                                                                                                                                                                                                                              │
     │ 2. Intelligent Study Planning                                                                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                                                                                              │
     │ Constraint Solver Inputs:                                                                                                                                                                                                                                                                                    │
     │ - Deadline proximity and assignment weight                                                                                                                                                                                                                                                                   │
     │ - Time-of-day productivity preferences (student-configured)                                                                                                                                                                                                                                                  │
     │ - AI-estimated assignment difficulty/effort                                                                                                                                                                                                                                                                  │
     │ - Mental energy and context-switching costs (group similar work)                                                                                                                                                                                                                                             │
     │ - Historical patterns from student behavior                                                                                                                                                                                                                                                                  │
     │                                                                                                                                                                                                                                                                                                              │
     │ Output:                                                                                                                                                                                                                                                                                                      │
     │ - Recommended time-blocked study sessions                                                                                                                                                                                                                                                                    │
     │ - Flexible placement - suggest durations, student confirms times                                                                                                                                                                                                                                             │
     │ - Proactive rebalancing when new assignments added or plans missed                                                                                                                                                                                                                                           │
     │                                                                                                                                                                                                                                                                                                              │
     │ 3. AI Tutoring System                                                                                                                                                                                                                                                                                        │
     │                                                                                                                                                                                                                                                                                                              │
     │ Multi-Provider Support:                                                                                                                                                                                                                                                                                      │
     │ - Anthropic Claude (primary recommendation)                                                                                                                                                                                                                                                                  │
     │ - OpenAI GPT-4                                                                                                                                                                                                                                                                                               │
     │ - Google Gemini                                                                                                                                                                                                                                                                                              │
     │ - Local models via Ollama (privacy-focused option)                                                                                                                                                                                                                                                           │
     │ - Provider abstraction layer for easy addition of new providers                                                                                                                                                                                                                                              │
     │                                                                                                                                                                                                                                                                                                              │
     │ Context-Aware Intent Detection (layered approach):                                                                                                                                                                                                                                                           │
     │ 1. Explicit mode toggle (student clicks "homework help" vs "learn mode")                                                                                                                                                                                                                                     │
     │ 2. Course context (proximity to due dates suggests assignment work)                                                                                                                                                                                                                                          │
     │ 3. Question analysis (AI examines phrasing for intent signals)                                                                                                                                                                                                                                               │
     │ 4. Behavioral patterns (learned from student's interaction history)                                                                                                                                                                                                                                          │
     │                                                                                                                                                                                                                                                                                                              │
     │ Academic Integrity Handling:                                                                                                                                                                                                                                                                                 │
     │ - Gentle redirect when direct-answer-seeking detected                                                                                                                                                                                                                                                        │
     │ - Acknowledge the question, explain why approach is different                                                                                                                                                                                                                                                │
     │ - Seamlessly transition to Socratic guiding questions                                                                                                                                                                                                                                                        │
     │ - Never hard-block or shame the student                                                                                                                                                                                                                                                                      │
     │                                                                                                                                                                                                                                                                                                              │
     │ Persona: Wise mentor                                                                                                                                                                                                                                                                                         │
     │ - Warm but authoritative tone                                                                                                                                                                                                                                                                                │
     │ - Proactive check-ins ("How's that calculus problem set going?")                                                                                                                                                                                                                                             │
     │ - Encouraging without being condescending                                                                                                                                                                                                                                                                    │
     │ - References student's actual courses and materials                                                                                                                                                                                                                                                          │
     │                                                                                                                                                                                                                                                                                                              │
     │ 4. Note Processing & Study Materials                                                                                                                                                                                                                                                                         │
     │                                                                                                                                                                                                                                                                                                              │
     │ Note Capture:                                                                                                                                                                                                                                                                                                │
     │ - Upload photos/scans of handwritten or typed notes                                                                                                                                                                                                                                                          │
     │ - Hybrid processing: OCR for text, vision models for diagrams/equations                                                                                                                                                                                                                                      │
     │ - Support for multiple images per topic/lecture                                                                                                                                                                                                                                                              │
     │                                                                                                                                                                                                                                                                                                              │
     │ Study Guide Generation:                                                                                                                                                                                                                                                                                      │
     │ - AI synthesizes notes into structured study guides                                                                                                                                                                                                                                                          │
     │ - Generic approach - rely on AI to adapt to subject matter                                                                                                                                                                                                                                                   │
     │ - Export as in-app view or downloadable document (PDF, markdown)                                                                                                                                                                                                                                             │
     │                                                                                                                                                                                                                                                                                                              │
     │ Practice Exam Generation:                                                                                                                                                                                                                                                                                    │
     │ - Free-form Q&A (AI generates, student answers freely)                                                                                                                                                                                                                                                       │
     │ - Structured formats (multiple choice, fill-in-blank, matching) - auto-gradable                                                                                                                                                                                                                              │
     │ - Bloom's taxonomy tagging (knowledge → synthesis) for difficulty calibration                                                                                                                                                                                                                                │
     │ - Mix question types based on subject and student preference                                                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                                                                                              │
     │ 5. Personal Analytics Dashboard                                                                                                                                                                                                                                                                              │
     │                                                                                                                                                                                                                                                                                                              │
     │ Tracked Metrics:                                                                                                                                                                                                                                                                                             │
     │ - Study time logged by course and activity type                                                                                                                                                                                                                                                              │
     │ - Task completion rates and deadline adherence                                                                                                                                                                                                                                                               │
     │ - Practice exam performance trends                                                                                                                                                                                                                                                                           │
     │ - Productivity patterns (best times of day, session lengths)                                                                                                                                                                                                                                                 │
     │                                                                                                                                                                                                                                                                                                              │
     │ Visualizations:                                                                                                                                                                                                                                                                                              │
     │ - Streaks and consistency tracking                                                                                                                                                                                                                                                                           │
     │ - Comparative views (this week vs last week)                                                                                                                                                                                                                                                                 │
     │ - Course-by-course breakdown                                                                                                                                                                                                                                                                                 │
     │ - Gentle, non-judgmental presentation                                                                                                                                                                                                                                                                        │
     │                                                                                                                                                                                                                                                                                                              │

     │ Technical Architecture                                                                                                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                                                                                              │
     │ Frontend                                                                                                                                                                                                                                                                                                     │
     │                                                                                                                                                                                                                                                                                                              │
     │ Framework: React + TypeScript (chosen for ecosystem maturity, extensive UI libraries, and community support for complex state management needed by constraint solver visualization)                                                                                                                          │
     │                                                                                                                                                                                                                                                                                                              │
     │ Key Libraries:                                                                                                                                                                                                                                                                                               │
     │ - TanStack Query for server state                                                                                                                                                                                                                                                                            │
     │ - Zustand for client state                                                                                                                                                                                                                                                                                   │
     │ - React Router for navigation                                                                                                                                                                                                                                                                                │
     │ - Tailwind CSS for styling                                                                                                                                                                                                                                                                                   │
     │ - Radix UI or shadcn/ui for accessible components                                                                                                                                                                                                                                                            │
     │ - FullCalendar or custom calendar implementation                                                                                                                                                                                                                                                             │
     │ - Chart.js or Recharts for analytics visualizations                                                                                                                                                                                                                                                          │
     │                                                                                                                                                                                                                                                                                                              │
     │ Client-Side Storage                                                                                                                                                                                                                                                                                          │
     │                                                                                                                                                                                                                                                                                                              │
     │ Database: Dexie.js wrapping IndexedDB                                                                                                                                                                                                                                                                        │
     │ - Friendly API for complex queries                                                                                                                                                                                                                                                                           │
     │ - Good TypeScript support                                                                                                                                                                                                                                                                                    │
     │ - Established ecosystem for local-first patterns                                                                                                                                                                                                                                                             │
     │ - Native IndexedDB performance                                                                                                                                                                                                                                                                               │
     │                                                                                                                                                                                                                                                                                                              │
     │ Sync Layer: Yjs for CRDT-based P2P synchronization                                                                                                                                                                                                                                                           │
     │ - Most mature CRDT library                                                                                                                                                                                                                                                                                   │
     │ - Awareness protocol for multi-device presence                                                                                                                                                                                                                                                               │
     │ - WebRTC provider for direct P2P                                                                                                                                                                                                                                                                             │
     │ - Well-documented, active development                                                                                                                                                                                                                                                                        │
     │                                                                                                                                                                                                                                                                                                              │
     │ Backend (Serverless)                                                                                                                                                                                                                                                                                         │
     │                                                                                                                                                                                                                                                                                                              │
     │ Platform: Cloudflare Workers or Vercel Edge Functions                                                                                                                                                                                                                                                        │
     │ - Scale to zero (cost-effective for open source)                                                                                                                                                                                                                                                             │
     │ - Edge deployment (low latency)                                                                                                                                                                                                                                                                              │
     │ - Easy deployment from GitHub                                                                                                                                                                                                                                                                                │
     │                                                                                                                                                                                                                                                                                                              │
     │ Responsibilities:                                                                                                                                                                                                                                                                                            │
     │ - AI API proxy (handles provider abstraction)                                                                                                                                                                                                                                                                │
     │ - Optional: TURN server relay for P2P when direct connection fails                                                                                                                                                                                                                                           │
     │ - Optional: Signaling server for WebRTC peer discovery                                                                                                                                                                                                                                                       │
     │                                                                                                                                                                                                                                                                                                              │
     │ Note: No persistent backend storage - all user data in client                                                                                                                                                                                                                                                │
