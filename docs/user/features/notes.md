# Notes

Upload photos of your handwritten or typed notes, and Lockdn extracts and organizes the content. This guide covers capturing, processing, and using your notes.

---

## Uploading Notes

### Supported Formats

- **Images**: PNG, JPG, JPEG, HEIC (iPhone photos automatically converted)
- **PDF documents**: Extracted page by page
- **Word documents**: Text extracted directly

### How to Upload

1. Go to **Notes** in the main menu
2. Click **Upload Notes**
3. Select one or more files
4. Choose the course these notes belong to (optional)
5. Click **Upload**

### Tips for Good Uploads

For best text extraction:

- **Good lighting** — Avoid shadows and glare
- **Flat surface** — Keep notes flat when photographing
- **Clear handwriting** — Neater writing extracts better
- **Full page** — Capture the entire page in frame
- **High resolution** — Use your camera's default resolution

> **Tip:** Most phone cameras work great. Just make sure the text is readable in the photo.

---

## Automatic Processing

When you upload notes, Lockdn:

1. **Extracts text** — Using AI vision to read handwritten or printed content
2. **Generates a summary** — Key points from your notes
3. **Identifies topics** — Tags for organization
4. **Suggests a title** — Based on the content
5. **Detects course** — If course codes or names appear in the notes

### Processing Status

While notes process:

- A loading indicator shows progress
- You can continue using Lockdn
- Notes appear in your list once ready

> **Note:** Processing requires an AI provider. Configure one in Settings if you haven't already.

## Organizing Notes

### Viewing Your Notes

Go to **Notes** to see all uploaded notes. You can:

- **Filter by course** — See notes for one course
- **Search** — Find notes by content or title
- **Sort** — By date, course, or title

### Note Details

Click any note to see:

- **Original image(s)** — Your uploaded files
- **Extracted text** — What Lockdn read from the image
- **Summary** — AI-generated key points
- **Topics** — Tagged topics for organization
- **Related materials** — Study guides generated from this note

### Editing Notes

You can edit note details:

1. Open the note
2. Click **Edit**
3. Update the title, course, or topics
4. Click **Save**

> **Note:** You can edit metadata, but extracted text is read-only. Upload a clearer image if extraction was poor.

## Multiple-Image Notes

For topics spanning multiple pages:

### Uploading Multiple Images

1. Select all images for one set of notes
2. Upload them together
3. They're saved as a single note with multiple images

### When to Use This

- Lecture notes spanning several pages
- Multi-page handouts
- Sequential content that belongs together

## Note Processing Details

### What AI Extraction Does

The AI vision model:

- Reads handwritten text (cursive and print)
- Interprets diagrams and figures
- Recognizes mathematical notation
- Identifies headers and structure
- Handles multiple languages

### Extraction Quality

Extraction accuracy depends on:

- Handwriting legibility
- Image quality
- Page contrast
- Content complexity

> **Tip:** Diagrams and complex equations may not extract perfectly. The original image is always preserved.

### Course Detection

Lockdn tries to match notes to courses by looking for:

- Course codes (e.g., "PSY 101")
- Course names
- Professor names
- Subject-specific terminology

You can always manually assign or change the course.

## Managing Storage

Notes with images can use significant storage.

### Checking Usage

Your browser's storage is limited. Check usage in:

**Settings** → **Data Management** → **Storage**

### Reducing Storage

- Archive old semester notes
- Delete notes you no longer need
- Export important notes before deleting

### Exporting Notes

To save notes outside Lockdn:

1. Open the note
2. Click **Export**
3. Choose format (text or with images)
4. Save to your computer

## Tips for Success

### Capturing Notes

- **Photograph right after class** — While context is fresh
- **Label pages** — Write course and date on physical notes
- **Use consistent formatting** — Makes extraction more reliable

### Organizing Notes

- **Assign to courses** — Keep notes organized by class
- **Use meaningful titles** — "Lecture 5 - Thermodynamics" beats "IMG_4521"
- **Tag topics** — Add topics for better searchability

### Using Notes Effectively

- **Review extractions** — Verify important information
- **Generate study guides** — Turn notes into study materials
- **Link to study sessions** — Access relevant notes while studying

## Troubleshooting

### "Extraction missed some text"

- Check image quality — Is the text clear in the photo?
- Try uploading a better image
- Some handwriting styles are harder to read

### "Notes aren't processing"

- Check that you have an AI provider configured
- Verify your API key is valid
- Large images may take longer to process

### "Wrong course was detected"

1. Open the note
2. Click **Edit**
3. Change the course
4. Click **Save**

### "I need to delete a note"

1. Open the note
2. Click **Delete**
3. Confirm deletion

> **Warning:** Deleted notes cannot be recovered. Export important notes first.
