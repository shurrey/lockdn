# Getting Started with Lockdn

Get up and running with Lockdn in about 10 minutes. This guide walks you through initial setup and adding your first course.

---

## Before You Begin

Lockdn works in any modern web browser (Chrome, Firefox, Safari, or Edge). For the best experience, use a desktop or laptop computer.

To use AI features like the tutor and study guide generation, you'll need an API key from one of these providers:

- **Anthropic (Claude)** — Recommended for best results
- **OpenAI (ChatGPT)**
- **Google (Gemini)**
- **Ollama** — Free, runs locally on your computer

Don't have an API key? You can still use Lockdn's core features (courses, calendar, notes) without one.

---

## Step 1: Open Lockdn

Navigate to Lockdn in your browser. The first time you open the app, you'll see a welcome screen introducing the key concepts.

> **Tip:** Bookmark Lockdn or add it to your home screen for quick access. Lockdn works offline once loaded.

---

## Step 2: Set Up Your AI Provider (Optional)

If you have an API key, set it up now:

1. Click **Get Started** on the welcome screen
2. Select your AI provider (Anthropic, OpenAI, Google, or Ollama)
3. Enter your API key
4. Click **Save**

Your API key is encrypted and stored only on your device. Lockdn never sends your key to any server except the AI provider.

> **Don't have an API key?** Click **Skip for Now**. You can add one later in Settings.

---

## Step 3: Upload Your Class Schedule (Optional)

If your school provides a class schedule image or PDF:

1. Click **Upload Schedule**
2. Select your schedule file (PDF, image, or screenshot)
3. Lockdn extracts your class times and creates courses automatically
4. Review the extracted courses and make any corrections
5. Click **Confirm**

> **Tip:** You can also add courses manually later if you prefer.

---

## Step 4: Upload Your Syllabi

For each course, upload the syllabus to automatically extract assignments:

1. Click **Upload Syllabus** for a course
2. Select the syllabus file (PDF, Word document, or image)
3. Lockdn shows extracted assignments with confidence scores
4. Review each assignment — edit titles, dates, or weights as needed
5. Uncheck any items that shouldn't be added
6. Click **Add Selected Items**

> **Important:** Always review extracted items. AI extraction is helpful but not perfect.

---

## Step 5: Set Your Study Preferences

Tell Lockdn when you study best:

1. Go to **Settings** → **Study Preferences**
2. For each day, mark your productive hours (morning, afternoon, evening)
3. Set your preferred break duration
4. Click **Save Preferences**

Lockdn uses this information to suggest study sessions when you're most alert.

---

## Step 6: Explore Your Dashboard

Your dashboard is now ready! Here's what you'll see:

- **Attention Cards** — Items that need your focus (upcoming deadlines, at-risk grades)
- **Today's Schedule** — Your classes and study sessions for today
- **Quick Actions** — Common tasks like adding notes or starting a study session

## Common First Steps

### "I want to add a course manually"

1. Go to **Courses**
2. Click **Add Course**
3. Enter the course name, code, and other details
4. Click **Save**

### "I want to add an assignment manually"

1. Go to **Courses** and select a course
2. Click **Add Assignment**
3. Enter the assignment details (title, due date, weight)
4. Click **Save**

### "I need to change my AI provider"

1. Go to **Settings** → **API Keys**
2. Add a new API key or update your existing one
3. Select your preferred provider
